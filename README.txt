هوش‌آرا — پنل‌های نقش‌محور
============================

صفحه‌ها:
- index.html: صفحه اصلی موجود
- role-select.html: انتخاب نقش برای حساب‌های چندنقشی
- panel.html: پنل شرکت‌کننده + نورون + لینک پشتیبانی
- lesson.html: درس + نتیجه بررسی مربی + نورون
- teacher-panel.html: پنل مربی
- teacher-activity.html: بررسی فعالیت و ثبت نورون
- support-student.html: پشتیبانی دانش‌آموز
- support-teacher.html: پشتیبانی مربی و ارتباط با دانش‌آموزان
- supervisor-panel.html: پنل سرپرست مجموعه
- styles.css: استایل اصلی و استایل‌های جدید

نکته:
این خروجی فرانت‌اند و نمونه تعاملی است؛ داده‌ها فعلاً نمایشی هستند و برای اتصال به بک‌اند/API آماده‌سازی شده‌اند.
